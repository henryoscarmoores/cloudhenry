=====================================================================
IF SOMETHING GOES WRONG
=====================================================================

The script will not send if anything is wrong, so you cannot break it
by running it. If you see the word STOP:

  [ ]  Do not send
  [ ]  Take a photo of the whole screen
  [ ]  Message Henry with the photo
  [ ]  Leave it. A week with no email is fine. A wrong email is not.

If the script will not start at all, or says it cannot find the Ghost
key, that is a computer problem, not something you did. Message Henry.
